# ELEVION / Opus Softworks — site institucional

Site institucional da ELEVION (tráfego pago, sistemas e serviços digitais), feito a partir do template Open PRO da Cruip adaptado à marca.

## Stack
- Next.js 15 (App Router, `next dev --turbopack`) + React + Tailwind CSS 4
- Gerenciador: pnpm (`pnpm-lock.yaml`)

## Comandos
- `pnpm install` · `pnpm dev` (localhost:3000) · `pnpm build` · `pnpm start` · `pnpm lint`

## Estrutura
- `app/` — layout e páginas; `components/` — seções (`hero-home`, `services`, `process`, `faq`, `cta`, `about`, `principles`, `guarantees`, `global-reach`, demos); `components/ui` — footer e afins
- `lib/`, `utils/`, `public/`

## Pendências conhecidas (README)
Placeholders entre colchetes a preencher: e-mail/WhatsApp (`components/cta.tsx`, `components/ui/footer.tsx`), cidade/UF e links de Instagram/LinkedIn/WhatsApp no rodapé.
